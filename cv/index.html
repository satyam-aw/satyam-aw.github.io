  • In Motion — HAR using DeepConvLSTM

    Built a data-driven mobile system that classifies real-time human activities using smartphone sensors and a remote deep learning inference engine.

    • Implemented a DeepConvLSTM core architecture using TensorFlow and Keras to track movement patterns over time.
    • Utilized a TimeDistributed CNN layer to compress sequential sub-windows into feature summary vectors, preventing vanishing gradients and optimizing battery consumption.
  • Autonomous Ground Vehicle & Swarm Robotics

    • Implemented visual obstacle segmentation (SegNet/U-Net) along with global (A*/Dijkstra) and local (DWA) path planners.
    • Researched decentralized swarm coordination using peer-to-peer relative pose estimation (AprilTags) over an ad-hoc XBee mesh network.
